# bloomind
En la investigación se realiza una exploración de una aplicación enfocada en el autocuidado y la salud mental, para conseguir información se realizó una encuesta digital a universitarios de la Universidad de Nariño, con toda la información obtenida se procedió a una fase de diseño, una vez realizado un prototipo del front-end y dividir el trabajo en 4 sprints con la metodología scrum se lleva a cabo la fase de desarrollo.

Prueba la aplicacion (apk): https://www.mediafire.com/file/4c5sli8smc6v7fj/BLOOMIND.apk/file
